**Normal Form (**Нормальная форма)** — это свойство отношения (таблицы) в реляционной базе данных, которое гарантирует отсутствие определённых аномалий при вставке, обновлении и удалении данных.

| NF           | Что устраняет (кратко)                     | Условие                                             |
| ------------ | ------------------------------------------ | --------------------------------------------------- |
| **[[1NF]]**  | Повторяющиеся группы, неатомарные значения | Все атрибуты атомарны, есть первичный ключ          |
| **[[2NF]]**  | Частичные зависимости от составного ключа  | 1NF + неключевой атрибут зависит от **всего** ключа |
| **[[3NF]]**  | Транзитивные зависимости                   | 2NF + неключевые атрибуты не зависят друг от друга  |
| **[[BCNF]]** | Зависимости от не-суперключей              | 3NF + детерминант каждой ФЗ — суперключ             |
| **[[4NF]]**  | Многозначные зависимости                   | BCNF + нет независимых многозначных зависимостей    |
| **[[5NF]]**  | Зависимости соединения                     | 4NF + отношение нельзя разбить без потери данных    |
| **[[6NF]]**  | — (крайняя степень)                        | Каждая таблица — один неключевой атрибут            |

**Практика:** в обычных приложениях останавливаются на **3NF** (иногда BCNF). 4NF–6NF — для специальных случаев.
