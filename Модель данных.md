

### Модели данных:

| Модель данных                                                                        | Краткое описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Типичная область применения                                                                                                                                                        |
| ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[[Реляционная БД\|Реляционные]]**                                                  | Данные организованы в таблицы (отношения) со строго заданной схемой; связи устанавливаются через первичные и внешние ключи. Управление осуществляется с помощью SQL, поддерживаются ACID-транзакции.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Транзакционные системы (банки, ERP, интернет-магазины), учет и системы с высокими требованиями к целостности данных.                                                               |
| **[[Иерархическая модель данных\|Иерархические]]**                                   | Данные представлены в виде древовидной структуры «родитель-потомок», где у каждого потомка только один родитель. Обеспечивает быстрый доступ при строгой навигации по структуре.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Файловые системы, реестр Windows, некоторые телекоммуникационные и авиационные системы бронирования (исторически).                                                                 |
| **[[Сетевая модель данных\|Сетевые]]**                                               | Расширение иерархической модели, где один потомок может иметь несколько родителей. Связи организованы в виде сложной сети (графа) с указателями.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Устаревшие корпоративные системы, некоторые системы бронирования авиабилетов и спутниковой связи.                                                                                  |
| **[[Объектно-ориентированная модель данных\|Объектные / Объектно-ориентированные]]** | Данные хранятся в виде объектов, напрямую соответствующих объектам в объектно-ориентированном программировании (классы, атрибуты, методы, наследование).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Сложные инженерные расчеты (CAD/CAM), системы мультимедиа, научные исследования, где важна прямая интеграция с ООП-кодом.                                                          |
| **[[Объектно-реляционная модель данных\|Объектно-реляционные]]**                     | Гибридная модель: реляционная основа дополнена объектными расширениями (пользовательские типы данных, наследование, сложные методы).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Приложения, которым нужна надежность реляционных БД, но требуется хранить сложные структуры данных (например, геоданные, мультимедиа).                                             |
| **[[Графовая модель данных\|Графовые]]**                                             | Данные представлены как узлы (сущности) и ребра (связи). Оптимизированы для выполнения сложных запросов по связям (обход графа).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Социальные сети, рекомендательные системы, обнаружение мошенничества, анализ связей и логистика.                                                                                   |
| **[[Мультимодельная модель данных\|Мультимодельные]]**                               | Единая СУБД, которая нативно поддерживает несколько моделей данных (например, документную, графовую и реляционную) в одном движке с общей транзакционной логикой.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Проекты, где необходимо обрабатывать разнородные данные (JSON, графы, пространственные данные) без развертывания нескольких разных систем и сложной синхронизации.                 |
| **[[Векторная модель данных\|Векторные]]**                                           | Данные хранятся в виде векторов — плотных массивов чисел (обычно сотни или тысячи измерений), которые кодируют семантику объектов (текста, изображений, аудио). Поиск основан не на точном совпадении, а на вычислении схожести (косинусное расстояние, евклидово расстояние) с использованием приближённых алгоритмов ближайших соседей (ANN) .[](https://dl.acm.org/doi/pdf/10.1145/3812734.3813407?download=true&__cf_chl_tk=TtC_NQj2dU7a99h1GUdymdwTDF1hNUx0IUWWDb8sguU-1784145284-1.0.1.1-sV5QhiMeZETZM7wqOv8Ma20KaMyWf1fI07ZETtJH92I#3#1)[](https://notes.kodekloud.com/docs/Vector-Database-for-GenAI/Introduction-to-Vector-Databases-and-Generative-AI/Vector-Databases-vs-Relational-and-NoSQL-Databases/page#integration-patterns-how-these-databases-work-together#1) | Семантический поиск, RAG (генерация с дополненной выборкой), рекомендательные системы, подбор похожих изображений/аудио, дедупликация и кластеризация неструктурированных данных . |
