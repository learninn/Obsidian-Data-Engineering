**DWH (Data Warehouse, хранилище данных)** — централизованное хранилище интегрированных, исторических, неизменяемых данных из разных источников, предназначенное для аналитики и принятия решений.

**Ключевые цели:**

- Консолидация данных из разнородных систем ([[ERP]], [[CRM]], биллинг, логи, API)
    
- Единая версия правды (single source of truth)
    
- Хранение истории (SCD, снапшоты, event sourcing)
    
- Разгрузка OLTP-систем от аналитических запросов
    
- Основа для BI, отчётности, ML, self-service analytics

**Чем НЕ является:**

- Не OLTP (не для транзакций)
    
- Не [[data lake]]
    
- Не операционная БД для приложений

## Классическая архитектура (Inmon vs [[Kimball]])

**Inmon (top-down):**

- Сначала нормализованное ядро (3NF), потом витрины
    
- Долго, дорого, но гибко
    
- EDW → Data Marts
